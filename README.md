# 成电招聘阅读助手

一个适用于 Microsoft Edge 的轻量浏览器扩展，用来改善电子科技大学就业网现场招聘页面的阅读和检索体验。

> 本项目为非官方工具，与电子科技大学及其就业指导部门无隶属或授权关系。招聘信息及相关内容的权利归原网站和信息发布单位所有。

## 功能

- 在新标签页打开招聘详情，保留原列表的页码、筛选条件和滚动位置。
- 按公司名称或招聘标题进行全局关键词搜索。
- 筛选现场招聘、组团招聘、空中宣讲、网上招聘和实习招聘。
- 搜索结果显示公司、招聘类型、标题、日期和地点，并支持分页。

## 安装方法

1. 下载本仓库，并解压到一个不会随意移动的文件夹。
2. 在 Microsoft Edge 地址栏输入 `edge://extensions` 并回车。
3. 打开左侧的“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择包含 `manifest.json` 的项目文件夹。
6. 打开或刷新电子科技大学就业网现场招聘页面。

已经安装旧版本时，在 `edge://extensions` 中找到“成电招聘阅读助手”，点击“重新加载”，然后刷新招聘页面。
